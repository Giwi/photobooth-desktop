Photobooth Desktop

A desktop photobooth for events and weddings. Live webcam feed, background overlays, photo strips, countdown capture - with keyboard and gamepad support.

Capabilities

Features

Everything a photobooth needs, out of the box.

Live webcam

Real-time preview, camera switching and mirror mode.

Background overlays

Drop in any image; position it top, center or bottom.

Photo strip

Classic 4-shot strip in a single picture.

Countdown capture

3, 5 or 10 second countdown with flash.

Print & save

Save photos, send them to a printer, or both.

Keyboard & gamepad

Full rebinding for guests who prefer buttons.

Watermark

Event name or date stamped on every shot.

7 themes

Dark, light, violet, orange, cyan, graphite, rose.

Guest friendly

Gamepad controls

Plug in a Super NES style pad and guests can drive the whole booth without touching the keyboard. Bindings shown are the defaults, re-mappable from Settings - Gamepad.

Y Print X Save B Cancel A Capture Prev background Next background Mirror Strip

A = Capture, B = Cancel, X = Save, Y = Print, D-pad = switch background, Select = Mirror, Start = Strip. Bindings re-mappable from Settings - Gamepad. Controller illustration from Wikimedia Commons.

Get it

Download

Grab the latest package for your platform from the releases page, or download directly below.

Linux
Download .deb Download .rpm Download AppImage
Windows
Download .exe installer

Install a webcam and (optionally) a printer. Plug in a gamepad for guest-friendly capture.

Debian / Ubuntu: sudo apt install ./photobooth-desktop_0.0.5_amd64.deb

Fedora / RHEL: sudo dnf install ./photobooth-desktop-0.0.5.x86_64.rpm

Any Linux: chmod +x Photobooth-0.0.5.AppImage && ./Photobooth-0.0.5.AppImage

Windows: run the installer.

Drop background images into the Settings → Backgrounds tab, pick a theme, and start the party.
